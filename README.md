# 🎭 Theatre notifier bot — Smart Ticket Availability Monitor

**Stop refreshing ticket pages. Never miss a chance to see your favorite show.**

Theatre Notifier is an automated ticket discovery and notification service designed to help theatre enthusiasts secure hard-to-find tickets.
Choose a preferred theatre and run bot - just at the moment when bot finds a seat, it sends a notification via Telegram with link and seat info

The service continuously monitors ticket availability across multiple performances and delivers actionable Telegram alerts when seats become available — turning the frustrating process of manually checking sold-out shows into an effortless experience.

### ✨ Highlights

- 🔎 **Automated Ticket Discovery** — Monitors multiple performances and detects available seats.
- ⚡ **Frequent Availability Checks** — Scans ticketing pages every 15 minutes.
- 🔔 **Telegram Notifications** — Sends show details, dates, available seat counts, and direct links to ticket pages.
- 🎯 **Smart Availability Detection** — Uses browser automation to extract seat availability from dynamically rendered booking interfaces.

**Tech Stack:** Node.js · JavaScript · Puppeteer · Telegram Bot API
